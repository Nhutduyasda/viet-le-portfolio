# QA Gates

## Run after every phase
- [ ] App starts without runtime error
- [ ] No TypeScript errors
- [ ] No lint errors
- [ ] Production build passes
- [ ] No obvious console warnings
- [ ] No invented professional facts
- [ ] Layout works at 375px width
- [ ] Layout works around 768px width
- [ ] Layout works at 1440px width

## Visual QA
- [ ] Light theme remains dominant
- [ ] Background is warm/off-white rather than pure harsh white everywhere
- [ ] Green is restrained
- [ ] Spacing feels generous
- [ ] Typography is consistent
- [ ] Buttons are not oversized
- [ ] Cards are not overused
- [ ] No unnecessary gradients
- [ ] No full-screen dark section introduced without approval

## Accessibility QA
- [ ] Heading hierarchy is logical
- [ ] All meaningful images have alt text
- [ ] Decorative images use empty alt
- [ ] Interactive elements are keyboard reachable
- [ ] Focus states are visible
- [ ] Contrast is acceptable
- [ ] Motion respects reduced-motion preferences

- [ ] Dates are owner-verified
- [ ] Project numbers are owner-verified
- [ ] Certifications are described accurately
- [ ] No wording implies credentials not actually held
- [ ] Public contact info is owner-approved
