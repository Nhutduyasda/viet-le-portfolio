# Build Roadmap

## Phase 0 — Repository Foundation
Goal: create a clean, production-ready base.

Deliverables:
- app boots successfully
- TypeScript / Tailwind configured
- global design tokens
- base layout
- content/config layer
- lint + typecheck + build working

## Phase 1 — Visual Foundation + Header + Hero
Goal: establish the full art direction.

Deliverables:
- responsive header
- premium hero
- CTA
- image treatment
- typography scale
- spacing system

## Phase 2 — About + Expertise
Goal: explain Viet's professional value clearly.

Deliverables:
- concise About section
- 4–6 expertise areas
- subtle visual hierarchy

## Phase 3 — Experience Timeline
Goal: show career progression without looking like a resume template.

Deliverables:
- responsive timeline/list
- clear company/title/dates
- readable descriptions

## Phase 4 — Selected Projects
Goal: make project credibility the visual centerpiece.

Deliverables:
- featured project component
- optional project grid
- metrics
- images
- project-detail-ready data model

## Phase 5 — Activities + Education + Contact
Goal: complete credibility and conversion.

Deliverables:
- professional activities
- education / training
- CTA/contact
- footer

## Phase 6 — Responsive + Accessibility + Performance
Goal: production quality.

Deliverables:
- mobile/tablet/desktop review
- keyboard navigation
- reduced motion
- image optimization
- Lighthouse-oriented improvements

## Phase 7 — SEO + Metadata + Social Preview
Goal: make the site shareable on LinkedIn.

Deliverables:
- title/description
- Open Graph metadata
- favicon
- social preview image placeholder/spec
- structured data where appropriate

## Phase 8 — Final Polish + Deployment
Goal: ship a portfolio safe to show the owner.

Deliverables:
- final content pass
- remove placeholders that should not ship
- deployment-ready build
- Vercel deployment instructions
- final QA report
