# Content Blueprint

## Content rule
Do not fabricate professional details. Keep unverified fields explicitly marked `TBD`.

## Suggested content model
Create a single content/config file, for example:
`src/content/profile.ts`

Suggested structure:

```ts
export const profile = {
  name: "Viet Le",
  headline: "Senior Project Development Engineer",
  domains: ["Solar PV", "BESS", "Renewable Energy"],
  location: "Ho Chi Minh City, Vietnam",
  linkedinUrl: "TBD",
  email: "TBD",
  heroStatement: "Developing practical energy solutions for a more sustainable future.",
  about: "TBD — owner-approved biography",
  expertise: [],
  experience: [],
  projects: [],
  activities: [],
  education: [],
};
```

## Suggested copy style
Use short, factual sentences.

### Hero direction
**Viet Le**
Senior Project Development Engineer
Solar PV · BESS · Renewable Energy

Possible statement:
> Developing practical energy solutions for a more sustainable future.

### About direction
Focus on:
- renewable-energy project development
- technical/commercial coordination
- project management
- clean-energy transition

### Expertise categories
Potential categories, only if owner confirms relevance:
- Solar PV Development
- Battery Energy Storage Systems
- Project Development
- Project Management
- Energy Market / DPPA
- Stakeholder Coordination

### Experience
For each role:
- company
- title
- start/end
- location
- 2–4 responsibility bullets or one short paragraph

### Selected Projects
For each project:
- title
- location
- capacity / metric if verified
- client/company if public and approved
- Viet's role
- challenge
- contribution
- outcome
- image

### Professional activities
Examples:
- training
- conferences
- industry workshops
- certifications

### Contact
Primary CTA should be LinkedIn.
Email can be secondary if owner approves public display.
