# Phase 5 Prompt — Professional Activities, Education & Contact

## Objective
Complete the professional story and create a clear closing CTA.

## Build
### Professional Activities
- training
- workshops
- industry events
- certifications or professional development

### Education
- institution
- program/degree if verified
- dates if verified

### Contact
Primary CTA:
- Connect on LinkedIn

Secondary CTA only if approved:
- email

### Footer
Minimal and professional.

## Rules
- Never describe training as a certification if it was only a course.
- Never expose private contact info without approval.

Run lint/typecheck/build before completion.
