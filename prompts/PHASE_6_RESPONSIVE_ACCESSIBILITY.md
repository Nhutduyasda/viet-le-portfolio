# Phase 6 Prompt — Responsive, Accessibility & Performance

## Objective
Audit the entire site as a production website, not a design mockup.

## Tasks
- test mobile, tablet, desktop layouts
- fix text wrapping and section spacing
- improve keyboard navigation
- verify focus styles
- verify heading structure
- add/fix alt text
- honor reduced motion
- optimize images
- remove layout shift where possible
- reduce unnecessary JS/client components
- check color contrast

## Performance priorities
- keep client-side JS minimal
- use optimized images
- avoid oversized animation libraries if not needed
- avoid unnecessary third-party scripts

Run lint/typecheck/build before completion and summarize issues fixed.
