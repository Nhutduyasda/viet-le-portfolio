# Phase 1 Prompt — Visual Foundation, Header & Hero

Continue the Viet Le portfolio. Read `AGENTS.md`, `DESIGN_SYSTEM.md`, and the existing implementation first.

## Objective
Make the first screen immediately communicate a premium, light, Scandinavian renewable-energy personal brand.

## Build
- minimal responsive header
- name/wordmark
- anchor navigation
- LinkedIn CTA
- hero with identity, role, domains, statement, and image area
- subtle entrance animation with reduced-motion support
- responsive behavior for mobile/tablet/desktop

## Hero content direction
Use owner-verified data from the content file.
If missing, keep placeholders clearly centralized in content data, not scattered in JSX.

Suggested framing:
- Viet Le
- Senior Project Development Engineer
- Solar PV · BESS · Renewable Energy
- "Developing practical energy solutions for a more sustainable future."

## Visual requirements
- warm off-white page
- deep green/dark neutral typography
- restrained accent green
- generous whitespace
- editorial image crop
- no dark full-screen hero
- no glassmorphism
- no neon

## Acceptance criteria
The hero should feel complete enough to screenshot and show the owner for direction approval.

Run lint/typecheck/build before completion.
