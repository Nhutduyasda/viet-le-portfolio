# Phase 3 Prompt — Professional Experience

## Objective
Present Viet's career progression with strong hierarchy and credibility.

## Build
- responsive experience timeline or editorial list
- company
- title
- dates
- location if useful
- concise role description
- optional domain tags

## Rules
- read experience data from the content layer
- do not fabricate dates or responsibilities
- if data is missing, render only verified fields or hide incomplete entries
- avoid resume-template visuals

## Visual direction
Think "executive profile" rather than "job application CV".
Use whitespace, dividers, typography, and subtle green accents.

Run lint/typecheck/build before completion.
