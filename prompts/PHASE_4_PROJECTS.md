# Phase 4 Prompt — Selected Projects

## Objective
Turn selected energy projects into the strongest proof section on the website.

## Build
- one large featured project component
- support additional projects if content exists
- project image
- title/location
- verified metrics
- Viet's role/contribution
- short outcome/context
- data-driven component structure

## Important
Do not publish private client information unless it has been explicitly approved.
Do not invent capacity, savings, emissions reductions, dates, or project roles.

## Visual direction
Use large editorial image layouts and project metrics.
Avoid generic card grids unless there are many projects.

## Acceptance criteria
Projects should look credible enough to be used as a real professional case study.

Run lint/typecheck/build before completion.
