# Phase 8 Prompt — Final Polish & Deployment

## Objective
Prepare a version safe to send directly to Viet for review.

## Tasks
- inspect every section visually
- remove accidental placeholders
- confirm all facts against approved content
- confirm all links
- review mobile navigation
- smooth small visual inconsistencies
- remove dead code and unused dependencies
- run full lint/typecheck/build
- prepare Vercel deployment
- document environment variables if any

## Final report must include
- final route(s)
- features completed
- content still requiring owner confirmation
- known limitations
- build/test status
- deployment steps

Do not add new features in this phase unless they fix a clear usability or release issue.
