# Phase 2 Prompt — About & Expertise

## Objective
Explain Viet's professional positioning in a concise, credible way without turning the page into a CV.

## Build
### About
- short editorial heading
- 1–2 concise paragraphs
- optional small supporting image/detail

### Expertise
Create 4–6 expertise items from verified content.
Prefer elegant text blocks or restrained cards.

Possible categories only if verified:
- Solar PV Development
- Battery Energy Storage Systems
- Project Development
- Project Management
- Energy Market / DPPA
- Stakeholder Coordination

## Visual direction
Keep the section light and spacious.
Avoid icon overload.
Avoid skill percentages.
Avoid generic software-style feature cards.

## Acceptance criteria
A new visitor should understand Viet's domain and professional value within 20–30 seconds of scrolling.

Run lint/typecheck/build before completion.
